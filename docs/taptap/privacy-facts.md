# 隐私政策编写所需的实际数据清单

这是按当前源码梳理的技术事实，供开发者完善发布主体、联系渠道、处理期限和正式隐私政策；不是已上线的隐私政策，也不是合规认证结果。

| 功能 | 当前处理方式 |
| --- | --- |
| 单人战役与设置 | 当前网页来源的 localStorage 保存战役进度、卡牌收集、声音设置等；Android 在应用私有 WebView 数据中保存，与其他浏览器/设备分开。 |
| 自有服务器身份 | 首次联网由服务器创建随机访客 ID 和随机凭据；客户端保存凭据，服务器持久化凭据的 SHA-256 摘要以验证后续连接。 |
| 昵称与段位 | 服务器保存昵称、积分、局数、胜负、操作类型计数及最近对局记录；这些名片信息会在联机界面展示。 |
| 房间 | 房间码、标题、简介、玩家昵称及对局状态供其他棋手查询；对局快照在双方间传输，活动房间保存在服务进程内存中。 |
| TapTap H5 宿主授权 | 仅调用宿主授权流程。临时 code 不落盘、不输出到日志、不发给当前访客房间服务器；未实现 TapTap 账号绑定或跨设备云存档。 |
| 网络日志 | Web 代理和宿主可能按各自配置处理正常网络日志；正式政策需按实际部署确认，不能仅凭游戏源码断言“不记录 IP”。 |
| 广告与统计 | 当前未接广告、第三方广告标识符或第三方统计 SDK。后续启用广告前需按实际 SDK、数据用途和平台要求更新政策与授权流程。 |
| 设备权限 | 当前 Android 容器仅声明联网权限，不读取相册、联系人或位置；平台宿主自身的权限和政策独立。 |

清除网页数据或卸载 Android 应用会清除本机进度/访客凭据；这不等于删除服务器上的段位记录。当前源码未提供玩家自助删除服务器记录的 API，也没有跨端账号恢复能力，不能在政策中承诺这些已经存在。

正式上线前仍需补齐：可核实的运营主体与联系渠道、服务器实际托管及数据处理安排、记录保留和删除流程、适用的未成年人保护方案。昵称和房间简介当前仅做长度/控制字符限制及显示转义，尚无完整的敏感内容审核服务，不能宣称已完成平台要求的文本治理。
