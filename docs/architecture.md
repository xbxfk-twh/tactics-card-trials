# 架构

`apps/web` 是游戏的唯一规则来源；Android打包同一运行清单，联机服务加载同一无DOM规则引擎。

| 路径（相对 apps/web） | 职责 |
|---|---|
| `js/data/definitions.js` | 基础卡牌、技能与首领元数据 |
| `js/core/engine.js` | 行动验证、回合、状态、召唤、伤害与快照 |
| `js/core/ai.js` | 通过规则接口执行电脑行动 |
| `js/campaign/` | 遭遇、成长、装备和剧情 |
| `js/practice/` | 离线练习阵容与电脑设置 |
| `js/network/` | 房间客户端、段位规则与平台适配 |
| `js/ui/` | 场景、交互、信息、音效和Canvas特效 |
| `server/` | 大厅、房间权威状态、身份摘要和段位持久化 |
| `tests/` | 规则/网络测试与可选浏览器流程 |
| `tools/` | 清单检查、启动、构建和素材再生成 |

界面将意图交给规则引擎，成功执行后产生已结算事件，由特效与声音消费。重绘不重复执行规则。联机由服务器验证行动，客户端读取快照。

战役遭遇只覆盖当前实例属性，不修改基础卡牌。联机与练习使用统一基础卡牌；余烬独行有独立主角和存档。

`runtime.json` 列出运行文件，`tools/check-assets.cjs` 收集实际资源引用；缺失或未引用资源都会报错。Android与两种ZIP共用该清单。
