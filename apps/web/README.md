# 战棋 · 卡牌试炼

浏览器试玩版与双人房间服务器。`js/core/engine.js` 管理战斗规则，`js/campaign/progress.js` 管理闯关收集，`js/core/ai.js` 负责电脑行动，`js/ui/app.js` 负责界面。`js/network/online.js` 和 `server/server.cjs` 提供浏览器测试房间；`js/network/tap-online.js` 提供 TapTap 小游戏联机适配层。

## 运行

安装 Node.js 后，在本目录执行：

```powershell
npm install
npm start
```

浏览器访问 `http://127.0.0.1:8080/`。两台设备测试时，使它们能访问同一台服务器，并在游戏的「联机 → 服务器与昵称」填写该服务器地址。

公网游玩：[战棋 · 卡牌试炼](https://guyuyizhang.top/tactics/)。网页自动连接同目录的 HTTPS/WSS 房间服务，无需额外填写地址。

单人闯关也可直接打开 `index.html` 离线试玩；联机必须运行服务器。

## TapTap 小游戏联机适配

若运行环境提供 `tap.getOnlineBattleManager`，联机界面自动使用 TapTap 的建房、房间 ID 加入和随机匹配；普通浏览器继续使用 WebSocket 测试服务器。TapTap 适配层会调用 `tap.login`，然后连接联机服务。房主运行现有规则引擎，处理双方行动；状态按 SDK 每条 2048 字节的限制分片同步。对手离开时会显示断线状态，房主仍在线时可按原房间 ID 重新加入并获取当前状态。

当前 H5 目录仍是 DOM 浏览器项目，**不是可直接上传的 TapTap 小游戏包**。要在 TapTap 真机里启用适配层，还需将界面与资源移植到小游戏运行环境并完成真机联机测试。房主裁定和本地存档可以用于玩法验证；正式金币结算及卡牌归属需要可信的云端存档与校验。

## 玩法

「星海会馆」提供实时房间大厅、房主简介编辑、准备开局和服务器保存的星图段位；「机巧练武庭」支持离线人机练习。公共卡池无需先收集十张卡。连接、段位规则与部署说明见 [联机部署与星图段位.md](docs/联机部署与星图段位.md)。

- 点击「战役」先选择旅程：原有十二关队伍战役「古树试炼」，或新增九关单主角战役「余烬独行」。独行主角烬行者可以强化属性与技能、搭配三项主动和两项被动、免费重置强化点。完整技能表和道具操作见 [余烬独行与道具.md](docs/余烬独行与道具.md)。
- 原战役技能卡可在战前「战役道具」携带两张，局内从手牌使用，每张每场一次，下场补齐；首领遗物装备后自动生效。移动至地上的 ✦ 自动拾取养料，本场生命与生命上限各 +5。
- 战役首领预警优先锁定出战角色；普攻横扫贴身敌军，对召唤物额外 +15 基础伤害；眩晕最多跳过一次行动，之后两次行动免疫眩晕。召唤物不再能反复吸引预警或逐只挡下普攻。

- 无 DIY 战役版：十二关章节路线展示敌军和 Boss 情报；第 6、9、12 关分别迎战苔岩守卫、熔炉暴君和虚空王后。Boss 实体占据 2×2 格，四格均可选中或攻击，无法穿过或叠放。首领在红方回合结束时显示橙色蓄力范围，玩家有完整回合走位；下次红方行动开始时结算法术伤害。半血后攻击与预警伤害各增加 6。
- 初始拥有古树。前五关按 1、2、2、3、4 人逐步扩编；前期敌阵和属性按关卡设计，第六关迎战首领，共 12 关。
- 首通时，每名出战角色获得 40 经验；40/100/180/280 经验升至 2/3/4/5 级，每级增加基础生命的 12% 和 2 攻击。商店与图鉴可花 10 金币训练获得 40 经验。旧存档自动兼容；成长仅用于战役，联机仍使用统一基础属性。
- 每关首次胜利得 10 金币并从三张未拥有卡中选一张。前四关保证奖励为角色，以满足第五关四人出战要求。
- 未拥有的角色卡和三张纯技能卡可在商店以每张 30 金币购买。全部卡牌集齐后，重复的关卡卡牌奖励改为 30 金币。
- 大厅默认使用公共基础卡池，无收集门槛，双方三选一、部署和对战；旧版自有卡池房间仍要求至少十张卡和四名角色。休闲不改变段位，排位由服务器结算星图积分。
- 游戏进度保存在当前浏览器的 `localStorage`。联机房间由服务器裁定行动，可用房间码加入与断线重连；房间在服务器重启后失效。

## 手机操作

卡牌属性在一个紧凑外框内，以符号和数字两列排列：❤️生命、⚔️攻击、🪖护甲、🎯射程、👣移动、⚡行动；护甲、🔷护盾和💠充能仅在数值大于0时显示，耗尽即隐藏，默认护盾也按实际卡牌显示。卡牌技能按三列小图标排列，点击查看说明；选卡、商店和阵容弹窗使用相同展示。实战仍可点击技能直接准备施放，点击旁边 ⓘ 或长按查看说明。

手机棋盘始终铺满可用页面宽度；较矮屏幕向下滚动查看控制区。点击强化、缠绕、光环等状态可读到具体效果、数值和持续时间，读取不消耗行动。治愈光环的宿主持续显示悬浮光环。刺客飞镖基础物理伤害为 20。

战役采用紧凑布局：两条战役的角色、关卡与出战按钮同屏显示。独行营地的「属性强化」「主动搭配」「被动搭配」，以及队伍营地的「调整阵容」「遗物与道具」均通过小按钮打开弹窗。详细剧情与首领机制在「关卡档案」。弹窗可点完成、右上角关闭、背景或按 Esc 关闭，配置自动保存。

对局采用完整棋盘加操作区，手机操作栏不会覆盖格子；常用技能直接显示，「技能档案」「手牌」「战报」「操作」从按钮弹窗查看。选择手牌后会回到棋盘选目标。手机优先保证棋盘全宽，控制区可向下滚动查看；内容较长的档案在弹窗内部滚动。

点击棋子查看生命、护盾、射程、行动和移动点，技能档案包含主动与被动说明。点击技能进入目标选择；长按技能 450 毫秒或点旁边的 ⓘ 打开说明，长按不消耗行动。冷却与不可用状态直接写在技能上，不可用技能仍可读取说明。橙色条纹为首领预警，绿/红/紫边框分别为移动/攻击/技能目标。电脑行动期间可以查看信息，不能代替电脑行动。

按钮点击、选中、取消、弹窗、施法准备、选卡确认、成功部署/移动、回合切换、格挡和胜负结算均有对应短音效。战斗动作按规则已接受的事件播放，双方联机共享，重绘/重连不重复播放。界面音效低于技能音量，批量事件限制叠音；「声音设置」中操作与战斗音效共用开关和音量，静音及切后台会停止当前声音，不在恢复后补播。全部本地合成，无新增网络音频请求。

新玩家音效默认80%；手动设定的音量和静音状态保留。

## 上线前仍需完成

H5 试玩版已部署公网，段位由服务器校验和持久化，身份为浏览器设备访客；尚未接入 TapTap 身份校验及云端战役进度。浏览器保存的战役卡牌和金币可被用户修改，因此**不能作为正式运营的奖励或解锁依据**。TapTap 上线前需要使用平台登录身份，在可信服务端保存收集和金币，并验证联机资格与胜利奖励；同时完成小游戏包体转换与真机测试。

技能机制、UI 和卡牌升级的审查见 [技能与升级评估.md](docs/技能与升级评估.md)。

## 游戏美术

首页场景与三位 Boss 使用内置 image_gen 生成的独立美术，已接入主页、关卡情报与棋盘。三位 Boss 采用苔岩根系、熔岩铜甲、紫晶王权三个视觉主题。UI 文字与美术分离，战场提示仍由实际规则生成。

运行资源：`assets/characters/boss-*-v1.webp`（512px、保留透明通道）及 `assets/backgrounds/campaign-hero*-v1.webp`（桌面与手机版）。高分辨率原稿不随公开仓库发布；来源分类见根目录 `THIRD_PARTY_NOTICES.md`。运行图仅做缩放与编码。

## 整理后的入口与打包

双击项目根目录的「启动游戏.cmd」即可启动并打开浏览器；再次启动会复用同一游戏服务。需要 Node.js；首次缺少依赖时自动安装。npm start 使用相同入口。

npm run check 校验运行文件和资产引用；npm run build 按 runtime.json 在根目录 dist/ 生成离线试玩 ZIP 和联机服务 ZIP。服务包包含 ws 依赖和启动入口，不包含 Node.js；原稿、环境、旧版、截图与测试不打包。更多说明见 docs/项目结构.md。

## 战役内容扩展

十二关包含连续的三幕短剧情与战术提示，剧情不会打断操作。第 6/9/12 关首通分别解锁苔岩之心、熔火余烬、王冠碎片；战前选择一件携带，仅作用于战役的原始出战角色。

已通关关卡可以回访。胜利、全员生还、在关卡建议回合内获胜分别对应一颗星，后两项目标独立判定。每颗新增的额外星级奖励 5 金币；重复挑战不会重复发放首通卡牌、金币或出战经验，最高星级不会降低。旧存档可直接回访来补星和领取已有首领的遗物。

## 战斗特效与叠放确认

普攻按近战、远程和炮击绘制刀光、弹道与冲击；施法按火焰、冰霜、自然、圣光、护盾、暗影和召唤等类型绘制。伤害、护盾吸收、格挡与治疗数字来自规则实际结算。独立 Canvas 层不拦截点击，按需动画、限制像素比和事件数，并响应系统减少动态效果设置；AI 和联机使用相同的已结算事件。最后一击保留短暂表现后进入结算。

纹理版特效使用Kenney的CC0粒子图集合成刀光、火焰、烟尘、星芒和光环，颜色缓存、减速碎屑、快速亮核及消散分层；弹道命中后显示结算数字。单张512×256 WebP图集约40KB，不加入额外渲染引擎。素材来源与参考见 [特效素材与参考.md](docs/特效素材与参考.md)。

移动、部署、位移技能或主动召唤导致与友军同格时，先显示叠放确认。弹窗列出目标格、已有成员和叠放后人数；取消或按 Esc 不执行指令、不消耗点数，也不清除待部署棋子。确认前再次校验对局状态，联机收到新状态会关闭过期确认。范围攻击与自动分裂不需要额外确认。

## 技能图标

39 项技能各有独立图标：32 个角色技能、3 张技能卡、3 种首领蓄力技能和半血狂暴。图标展示于施法按钮、被动技能、技能说明、图鉴、敌方情报与首领预警中；主动技能保留消耗、冷却和可用状态文字，被动技能点击查看，不作为施法按钮。图鉴顶部可展开全部技能图册。

补画的11张图标由image_gen生成，运行版位于 assets/icons/skill-*-v1.webp，最大96px，保留透明通道；页面常规显示24–32px。高分辨率原稿不随仓库发布。资源检查确保每项技能有独立图标，无缺失或无引用资源。

单位成功移动、普攻或施法后，如果移动点与行动点均为 0，则自动取消选中和技能目标状态；任一类点数仍有剩余则保持选中。可以重新点击已耗尽点数的单位查看信息，失败的操作不会自动取消。联机状态同步遵循同样规则。
