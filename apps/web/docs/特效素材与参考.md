# 特效素材与设计参考

运行纹理来自 Kenney 的 Particle Pack，CC0 1.0，可用于商业游戏；仅选用8张透明纹理，缩放并合成512×256图集，不包含整套素材包或Unity示例。源文件、原许可、归档哈希和帧映射位于根目录docs/licenses（来源）及artifacts/source-assets/kenney-particles（本地输入）。工具 `tools/import_vfx_textures.py` 可从保存的官方ZIP复现图集。来源：https://kenney.nl/assets/particle-pack ，许可说明：https://kenney.nl/support 。

Riot 的 Clarity in League 强调玩法信息、视觉主次和减少噪声：https://www.leagueoflegends.com/en-us/news/dev/clarity-in-league/ 。本项目参考这些原则，重新实现蓄势、弹道、瞬间亮核、烟尘碎屑和消散；不使用Riot的游戏贴图、代码或专属效果。

PixiJS Particle Emitter 的MIT开源示例展示透明度、颜色、尺寸和速度随生命周期变化：https://github.com/pixijs-userland/particle-emitter 。这里只参考设计思路，当前游戏继续使用现有Canvas渲染器，不加入Pixi运行依赖。
