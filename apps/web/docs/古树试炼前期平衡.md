# 古树试炼前期梯度

前五关按1、2、2、3、4人出战，首通角色奖励足够满足下一关人数，不要求额外购买。第一关教召唤/控制与移动，第二关引入双人集火，第三关处理近战加远程，第四关引入重甲和三人配合，第五关用四人满编练习完整战线，第六关仍是苔岩守卫。

前五关使用独立关卡敌人属性和部署位置，配置位于 `CampaignProgress.encounter`，`CampaignProgress.start` 将其交给规则引擎。界面预览读取同一份配置；实战、选中档案和快照保存使用实际数值。通用卡牌、联机、人机基础属性、余烬独行和第六关以后配置保持原值。

| 关卡 | 人数 | 敌阵：生命/攻击/正护甲/正护盾 |
|---|---|---|
|1|1|小史莱姆45/12|
|2|2|骷髅48/15、小树人38/12|
|3|2|小树人70/18、游侠60/18|
|4|3|骑士80/20/3/15、游侠65/20、兵55/17|
|5|4|史莱姆75/15、骷髅55/17、小树人60/17、兵60/18|

速通星级目标改为6、7、8、9、10回合。已有金币、角色、经验、最高星级和首通记录不回收，回访仍不重复发首通奖励。

`tests/party-balance.test.cjs` 用真实规则与AI，比较4类阵容、技能与只普攻两种策略、三种部署位置，探测前六关共144场，另有旧版前四关普攻基线。测试包含可通关构筑、后段盲普攻失败样本、预览与快照一致、基础定义不变及首通奖励满足编制。固定策略的结果仅作回归基线，不代表真人胜率，也不保证所有阵容都能通关。
