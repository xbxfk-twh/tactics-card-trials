# 技能、界面与升级评估

## 技能机制

当前数据包含 22 种角色/召唤单位、32 个角色技能和 3 张独立技能卡；选卡池只放角色与这 3 张独立技能卡。角色自带技能在战斗操作区显示，不作为独立选卡。

这次核查并修复了以下规则：

- 最后一回合的眩晕仍阻止零消耗技能。
- 冰霜新星、盾牌壁垒、隐匿和哈气以施法者为中心释放。
- 血爪仅由普通攻击吸血；直接锁定技能无法选取隐匿单位，范围伤害仍可命中。
- 傀儡最多同时四个，移动不能离主人超过两格；主人死亡时其傀儡消失。
- 小史莱姆死亡后留下可拾取的养料；棋盘死亡时随机散出一枚棋子。
- 车的冲撞在敌人前一格停下，王后的移动不能直接吃子，王后与马的法球遵守对应的直线/斜线或 L 型目标规则。
- 同格叠放多个单位时，单体攻击、技能和治愈光环可以明确选择目标。
- 「对弈」现在会交替结算最多六次普通攻击，与桌面版的攻击次数一致。浏览器版即时显示结果，尚未加入桌面版的 1×2 决斗空间动画，因此在 H5 导出时使用与当前展示相符的说明，原 Python 卡牌说明保持不变。

其余主动效果与三张纯技能卡已接入规则层。联机行动由服务器逐条验证。仍建议在玩家测试中重点观察眩晕四回合、永久护甲、治疗光环、远程炮台和恶魔陨石的强度；这些技能可以完整结算，但尚无真实玩家对战数据来判断数值平衡。

## UI

手机竖屏中，选卡三张可同时横向比较；战斗棋盘保持方形，操作区停靠在棋盘下方。角色技能详情在图鉴和选卡中可点开查看；选中技能后显示对应说明。叠放目标会弹出目标选择列表。大图鉴与奖励卡牌允许纵向滚动。

## 卡牌升级

当前不加入属性升级。闯关给新卡、商店提供补齐卡池的路径，已经形成明确的成长目标；属性升级会使联机胜负受历史投入影响，并增加 32 个技能的平衡组合。后续可优先考虑仅改变外观的熟练度、称号或卡面边框。若要加入数值升级，建议先将其限定在单人闯关，并等联机对战数据稳定后再决定是否扩展。
